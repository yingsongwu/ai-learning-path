# 00 · 总路线图

## 依赖关系（不能跳的原因）

```
01 线性代数 ──► 02 微积分 ──► 03 概率 ──► 05 神经网络 ──► 06 训练调优
     │                │                          │
     └──► 04 Python/numpy ──────────────────────┘
                                                │
                                     ┌──────────┴──────────┐
                                     ▼                     ▼
                                 07 CNN                08 Transformer
                                     │                     │
                                     └────────► 09 大模型应用 ◄──┘
                                                     │
                                                     ▼
                                              10 工程化部署
```

每根箭头的意思是：**后一个单元的代码里会出现前一个单元的概念**。
比如 05 的反向传播 = 02 的链式法则 + 01 的矩阵转置。

## 进度表（学完打勾）

### 阶段一 · 地基
- [ ] 01 线性代数：能说出每个矩阵乘法的形状，能手算点积
- [ ] 02 微积分：能手推两层网络的梯度并做数值校验
- [ ] 03 概率：能解释交叉熵 = 负对数似然
- [ ] 04 Python/numpy：不用 for 循环实现矩阵运算

### 阶段二 · 跑通模型
- [ ] 05 神经网络：从零实现前向+反向+训练，测试集 > 95%
- [ ] 06 训练调优：能诊断过拟合/欠拟合并给出 3 种解法

### 阶段三 · 选方向
- [ ] 07 CNN：在图像任务上超过 MLP 至少 3 个点
- [ ] 08 Transformer：从零写 attention，解释 Q/K/V
- [ ] 09 大模型应用：做一个能查资料并回答的 RAG 小助手

### 阶段四 · 落地
- [ ] 10 部署：模型导出 + HTTP 接口 + 压测数字

## 每单元的固定产出

| 产出 | 作用 |
|---|---|
| 可运行脚本 | 让概念变成"看得见的现象" |
| 一张图 | 记住图的形状，比背公式有效 |
| 练习题 | 手算，确认不是"看懂了" |
| 自测 8/10 | 过关门槛 |

## 常见误区

1. 先啃完数学再动手 → 会卡死。**先跑通，遇到不懂再回补**。
2. 跳过 01 直接学神经网络 → 反向传播那几行永远只能背。
3. 只看不写 → 判断"会了"的唯一标准是能默写出来并验证。
