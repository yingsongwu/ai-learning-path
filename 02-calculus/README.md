## 过关标准

`python check.py` **≥ 10/12**，并且能不看资料回答：

1. 导数的几何意义是什么？为什么 h 不能真取 0？
2. `(3x+1)²` 在 x=1 处的导数？步骤是哪两步相乘？
3. 求 ∂/∂y(x²+3y²) 时，x² 去哪了？
4. 为什么梯度方向是「上升最快」？
5. 反向传播里为什么加法节点的梯度是原样传下去？
6. dW 为什么一定和 W 形状相同？
7. 数值梯度里 h 为什么不能太大也不能太小？
8. lr 太大会发生什么？数学原因是什么？
