# 01 单元 · 手写练习（先自己做，再看答案）

> 用纸笔算，不要开电脑。会算和会看是两件事。

## A. 点积与相似度

1. `a=(2,1)`，`b=(1,3)`，求 `a·b` 和 `cos(a,b)`。
2. 什么样的两个向量点积为 0？在图像识别里意味着什么？
3. 把一张 16×16 的图展平成 256 维向量，两张图的点积很大说明什么？

## B. 矩阵与形状

4. `(3,4) @ (4,5)` 的结果形状？
5. `(3,4) @ (3,5)` 能乘吗？为什么？
6. `x(8,256) @ W(256,64) + b(64)`，输出形状？`b` 是怎么加到每一行上的？
7. 为什么 `W` 的形状是 `(输入维, 输出维)`，而不是反过来？

## C. 变换与秩

8. 矩阵 `[[0,-1],[1,0]]` 对向量 `(1,0)` 做了什么？
9. `[[2,0],[0,0.5]]` 把单位正方形的面积变成多少倍？
10. 三个 3 维向量 `(1,0,0)`、`(0,1,0)`、`(1,1,0)`，它们的秩是多少？

## D. 特征值与 SVD

11. `A=[[3,0],[0,1]]` 的特征值和特征向量？
12. 一张 1000×1000 的图做 SVD，只想保留 50 个奇异值，需要存多少个数字？原图要存多少？

## E. 深入（L7~L10）

13. 向量 `(3,4)` 的 L1、L2、L∞ 范数分别是多少？
14. 为什么 L1 正则能让很多权重恰好变成 0，而 L2 不会？
15. 5 个点、2 个未知数拟合直线，为什么不能用 `A⁻¹`？应该用什么？
16. `(4,10,32) @ (32,16)` 的结果形状？`@` 对哪两维做矩阵乘？
17. `einsum('bqd,bkd->bqk')` 里字母 `d` 为什么消失了？
18. PCA 前第一主成分解释 90% 方差，压成一维后重建误差主要来自什么？

---

## 答案

1. `a·b = 2*1 + 1*3 = 5`；`|a|=√5`，`|b|=√10`，`cos = 5/(√5·√10) ≈ 0.707`（45°）
2. 垂直（正交）。意味着两者"毫无相似之处"，网络里通常表示两个特征不相关。
3. 两张图很相似（逐像素亮度模式接近）。这正是模板匹配 / 卷积的直觉。
4. `(3,5)`
5. 不能。内维 4≠3，规则要求 `(n,k)@(k,m)`。
6. `(8,64)`；`b` 通过广播加到每一行（每个样本都加同一个偏置）。
7. 因为要做"输入维 → 输出维"的映射：`x·W` 里 W 的第 j 列就是第 j 个输出神经元的权重，长度必须等于输入维。
8. 逆时针旋转 90°，`(1,0) → (0,1)`。
9. `det = 2*0.5 = 1`，面积不变（一个方向拉长、一个方向压缩）。
10. 秩 2。第三个是前两个的和，没有带来新方向。
11. `λ₁=3, v₁=(1,0)`；`λ₂=1, v₂=(0,1)`。对角矩阵的特征向量就是坐标轴。
12. 存 `50*(1000+1000+1)=100,050` 个数，原图 `1,000,000` 个数 —— 压缩到约 1/10。
13. L1 = 7，L2 = 5，L∞ = 4。（L2 是 3-4-5 直角三角形）
14. L1 的"单位球"是菱形，顶点在坐标轴上：最优点容易落在顶点 → 某些坐标恰好为 0（稀疏）。
    L2 的单位球是圆的，最优点一般落在平滑处，只会把权重整体压小，不会正好等于 0。
15. 矩阵是 5×2（不是方阵），不能求逆。用最小二乘 `(AᵀA)⁻¹Aᵀy` 或 `np.linalg.lstsq`。
16. `(4,10,16)`。`@` 只对最右两维 `(10,32)@(32,16)` 做矩阵乘，batch=4 原样保留。
17. 因为 `d` 在两个输入里都出现，而输出里没有 → 表示沿这个维度求和（点积）。
18. 来自被丢掉的那个方向上的方差，也就是 `1-0.9=10%` 的信息；重建点只能落在主方向上。
