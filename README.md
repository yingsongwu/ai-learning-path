# AI 学习路线 · 逐级递进清单

> 一个文件夹 = 一个学习单元。每个单元都能**跑代码、出图、自测**，不是读书笔记。
> 从线性代数开始，一路走到能训练模型、能做 RAG 应用、能部署。

## 怎么用

0. **每天开工先看 `PROGRESS.md`**（进度看板，勾选式），学完就打勾。
1. 打开 `00-roadmap/README.md` 看依赖图与阶段划分。
2. 按编号顺序进文件夹，**不要跳**（后面依赖前面）。
3. 每个文件夹固定四件套：
   - `README.md` —— 学什么、为什么学、验收标准、预计用时
   - `*.py` —— 可运行的最小实验（`python 01_vectors.py`）
   - `exercises.md` —— 手写练习题（附答案，先自己做）
   - `check.py` —— 自测打分（`python check.py`，01 单元是 14 题、≥12 题过关）
4. 学完一个，把 `00-roadmap/README.md` 里的 `[ ]` 改成 `[x]`。

## 环境

只需要 Python 3.9+ 和两个包：

```bash
python -m pip install numpy matplotlib
```

无 GPU、无联网需求（数据和图都在本地生成）。
